# AI Office Company — Website

Single-page marketing website for [AI Office Company](https://aiofficecompany.com/), a New Orleans-based company that creates AI Offices for small businesses.

## About

AI Office is a virtual office space where AI handles repetitive tasks automatically, under human supervision. The company creates, configures, and manages these AI Offices for clients.

## Structure

```
ai-office-company-website/
├── index.html    # Complete single-file website (HTML + CSS + JS)
└── README.md
```

## Features

- Sticky navigation with CTA
- Animated hero section with canvas particle effect
- Interactive component cards with full-screen modal slideshows (keyboard + swipe navigation)
- How It Works, Trust, and Lead Capture sections
- Mobile-first, fully responsive
- Zero build step — deploy directly to Netlify by dragging the folder

## Deployment

Deploy to Netlify by dragging the `ai-office-company-website/` folder into the Netlify dashboard, or connect this GitHub repository for continuous deployment.

## Before Launch

- Update placeholder email `hello@aiofficeco.com` in the Lead Capture section
- Confirm LinkedIn URL: `https://linkedin.com/company/aiofficeco`
- Verify the Google Form CTA link is the final production URL

## Tech

Pure HTML/CSS/JS. No build tools. No frameworks. Inter font loaded from Google Fonts.
